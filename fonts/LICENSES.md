# Лицензии шрифтов

Проверено для макета **D** и будущей инструкции.

## Что используется в D

| Шрифт | Где используется | Лицензия | Можно ли встраивать в публичный HTML |
|---|---|---|---|
| **Kablammo** | Крупный заголовок | **SIL OFL 1.1** | Да, с текстом лицензии и копирайтом |
| **Tsap-Tsarap** | Подзаголовки, подписи | Автор пишет: **«Free font for any type of use»** | Да, но это не формальная лицензия; желательно указать автора и приложить readme |
| **Liberation Sans** | Основной текст | **SIL OFL 1.1** | Да, с текстом лицензии и копирайтом |

Полные тексты/условия лежат рядом:

- `licenses/Kablammo-OFL-1.1.txt`
- `licenses/Kablammo-COPYRIGHT.txt`
- `licenses/Tsap-Tsarap-README.txt`
- `licenses/Liberation-Sans-copyright.txt`

## Что ещё лежит в папке, но в D не используется

| Шрифт | Лицензия | Комментарий |
|---|---|---|
| **Noto Serif Display** | **SIL OFL 1.1** (`fonts-noto-core`) | Безопасен, если понадобится как запасной заголовочный шрифт |
| **Fasol SP Demo** | Бесплатная демо-версия, условия в `Short License.pdf` | Нет знаков препинания и цифр; для публичного текста не годится |
| **Mefestico** | **All Rights Reserved** | Не встраивать в публичный HTML без разрешения |
| **Penguin Attack** | **GPL v2** | Не встраивать в публичный HTML без юридической проверки |

## Что сделать перед публикацией

1. В `dist/fate_guide.html` добавить блок «Лицензии шрифтов» или комментарий с:
   - копирайтом Kablammo;
   - текстом OFL 1.1 для Kablammo;
   - копирайтом Liberation Sans;
   - текстом OFL 1.1 для Liberation Sans;
   - readme Tsap-Tsarap и указанием автора.
2. Если хочется формально «чистую» лицензию на все шрифты — заменить Tsap-Tsarap на OFL-шрифт с кириллицей (например, Caveat или Neucha). Они не установлены; можно скачать с Google Fonts, но это уже отдельное решение.
3. Mefestico, Penguin Attack и Fasol SP Demo в публичную сборку не включать.

## Состояние папки

Неиспользуемые шрифты (Fasol SP, Mefestico, Penguin Attack), их readme и zip-архивы вынесены из `fonts/` в архив, чтобы не нарушать лицензии при публикации. Используются только `Kablammo-Regular.ttf` и `Tsap-Tsarap.ttf`.
